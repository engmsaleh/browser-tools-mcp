Console Log Test Page

This page generates different types of console logs to test the BrowserTools MCP Firefox extension.

Instructions:

  1. Make sure the Firefox BrowserTools MCP extension is installed
  2. Open Firefox DevTools and navigate to the BrowserTools MCP panel
  3. Verify that the panel shows "Connected to WebSocket"
  4. Click the buttons above to generate different console logs
  5. Check if the logs appear in the browser-tools-server
